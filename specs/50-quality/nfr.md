# Non-functional requirements

Measured on the reference devices listed in `40-technical` (a mid-range laptop and a recent mid-range phone of each major phone platform).

| ID | Requirement | Measure |
|---|---|---|
| **NFR-01** | **Privacy and network.** The tool only ever requests its own files from its own origin, and no request carries media, project content or user data (PRN-01, INV-01). On the first online visit it fetches everything it can need, including looks, typefaces and bundled music (D-017); using any feature for the first time later makes no request. No analytics, no third-party code at runtime. | Network log over a full session using every M-1 feature, plus the security policy review. |
| **NFR-02** | **Start-up.** Usable (the empty state accepts a file) within 2 s on the reference laptop and 3 s on the reference phone on a first load over 10 Mbps with 40 ms round-trip time, and within 1 s from the offline cache. Fetching the rest of the files for offline use (NFR-01) continues in the background and never delays this. | Lab measurement, median of 5 runs. |
| **NFR-03** | **Preview smoothness.** The 1080p preview plays at ≥ 30 frames per second on the reference laptop and ≥ 24 on the reference phone. This holds with a look, every adjustment non-zero, a cross-fade, three text layers and music playing. The preview responds to a scrub or seek within 150 ms. | Frame timing during a scripted playback; seek latency, 95th percentile. |
| **NFR-04** | **Export speed.** 1080p30 video exports at ≥ 1× real time on the reference laptop and ≥ 0.5× on the reference phone. The fixture (a 60 s 9:16 clip from three phone videos with a title, a look and music) therefore exports in ≤ 75 s on the laptop and ≤ 150 s on the phone, including set-up. | Timed export of the fixture projects. |
| **NFR-05** | **Memory.** Memory use doesn't grow with source file size. A 10-minute 1080p project, and a 2-minute project from 4K sources, both preview and export on the reference phone without the page being closed by the system. | Peak memory during the fixture runs; with a 4 GB source, peak memory is within 10 % of the same edit made from a 100 MB source; crash count = 0 over 5 runs. |
| **NFR-06** | **Accessibility.** WCAG 2.2 AA. Every function is reachable by keyboard on desktop and by visible controls on touch, never only by a gesture. Controls have names, sliders have values, and announcements cover playback state, the selection and export progress. | Automated checks with zero violations, plus a manual screen-reader pass of FLOW-01. |
| **NFR-07** | **Layout.** Usable from 320 px wide to large desktop screens, in portrait and landscape, with no horizontal page scrolling. Phone portrait is a primary layout, not a fallback. | Screenshots at 320, 390, 768, 1280 and 1920 px, in both themes and both languages. |
| **NFR-08** | **Fidelity.** Exports match the preview (INV-02). *Video export:* each frame comes from within 1 frame of the same time in the preview; colour on a 24-patch test chart differs by mean ΔE00 < 2 and max < 4 over patch centres, at Balanced quality with Grain 0; sound stays within 40 ms of the picture across a 10-minute export. *GIF:* each frame is within one GIF frame of its preview time. *Audio export:* sample-aligned with the video export's sound within 1 ms. | Frame-diff, colour-chart and clap fixtures. |
| **NFR-09** | **Security.** Only allowed hosts can embed the tool or send it settings (RULE-17). The tool's security policy forbids network connections and code from other origins. Text from users is never interpreted as markup. | Security audit; tests for message origin and frame embedding. |
| **NFR-10** | **Size.** The tool's own code and styles at first load are ≤ 600 KB compressed, excluding fonts, looks and bundled music. Typefaces and look data ≤ 1.5 MB; bundled music ≤ 10 MB in total. Everything the tool needs is available offline after the first full visit (NFR-01). | Build report; offline test. |
| **NFR-11** | **Reliability.** A failed or cancelled export never changes or loses the project. Cancel takes effect within 1 s. After any export, scratch space is empty again (INV-01). | Fault-injection tests; storage inspection. |
| **NFR-12** | **Browser coverage.** All M-1 features work on the latest two versions of the three major desktop browser engines and of the main browsers on the two major phone platforms, as listed in `40-technical`. Anywhere else, RULE-22 applies. | Test matrix in QA. |
