# ADR amendments queued from spikes (apply at G3)
- **MOD-Engine:** a frame lasts until the next frame's start. Never use rounded durations. (SP-compositor)
- **ADR-0010:** remove the encoder's priming delay through an MP4 edit list (AAC, 2112 samples measured). (SP-compositor)
- **ADR-0004:** the trial encode measures encoder delay rather than assuming it. (SP-compositor)
- **ADR-0004:** probe only a minimal set at start-up (≤ 300 ms); probe the full size × rate grid when the export panel opens. Cap concurrency at 4. Normalise the AAC description to its 2-byte AudioSpecificConfig. WebKit's FLAC decode is a false positive. (SP-codec)
- **ADR-0009:** add a cache of intermediate decoded frames for long-GOP backward scrubbing, or document the worst case. WebKit's decoder needs flushes. (SP-compositor)
- **ADR-0010 and SP-storage:** WebKit gives the embedded frame 1/10 of standalone quota, so no_space is a real path. Scratch names are unique per session. The start-up sweep skips files still in use, because Chrome shares storage between same-site embedded and standalone. (SP-frame)
- **Audio:** bound the wait on WebKit's AudioContext.resume(). (SP-frame)
- **ADR-0005:** mediabunny does not throw on a missing moov, so MOD-Container maps "no tracks / 0 packets" to a typed error. (SP-license)
- **Audio ADR and ADR-0010 (from SP-audio):**
  - The limiter ceiling is −1.5 dBTP internally (BS.1770 meter, 4× side-chain).
  - AAC and Opus exports need a verify-and-trim pass: decode, check the true peak, and re-encode with a trim if it is above −1.3 dBTP (at most 3 passes).
  - Opus priming is 312 samples, removed via the edit list.
  - The worklet ring buffer is 400 ms.
  - The Web Audio graph variant is rejected.
  - WebKit's Opus encode overshoots by about 4 dB and its AAC encoder ignores `bitrate`: record both in the capability probe.
- **RULE-08 / F-007.AC2 (spec change, owner):** check the ramp bars on the high-precision render (CPU reference + half-float layer), at Grain 0, with Vignette checked per position. On 8-bit outputs, allow no reversal above ΔL* 0.5 and require ΔE00 ≤ 1 against the reference. 8-bit and limited-range outputs can't keep 256 distinct steps. (SP-gpu-color)
- **ADR-0006 §3.2:** use a half-float intermediate (renderable in all 3 engines), with an 8-bit fallback. Drop recompute-taps. (SP-gpu-color)
- **ADR-0007 / ADR-0010:** encoders differ: Chrome writes limited range, WebKit and openh264 write full range, and all tag transfer as sRGB (13). MOD-Export writes the `colr` tags explicitly. The owner's player check decides the transfer tag and whether we convert to limited range ourselves. (SP-gpu-color)
- **ADR-0007 §3 / ADR-0013:** a look is a 33³ 8-bit PNG of 4–15 KB measured, against a budget of 30 KB per look. The build rejects a look over 108 KB or with storage error above ΔE00 1. (SP-gpu-color)
- **platform-mapping.md (RULE-22):** slow device = the start-up effects check (full chain + look + Blur, 1080p, 30 frames) renders below 30 fps. (SP-gpu-color)
- **ADR-0016:** grade fidelity fixtures are RGB stills; the oracle is the CPU reference in float. (SP-gpu-color)
