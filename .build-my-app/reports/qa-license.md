# QA licence audit (Phase 5), 2026-11-20

Scope: package.json, installed tree (`pnpm licenses list --json`, read-only), `public/third-party-notices.txt`,
`src/app/notices.gen.ts`, `src/assets/{looks,music}`, `src/app/icons.tsx`, `tests/fixtures/media`, and the
policy in `specs/40-technical/dependencies.md` + ADR-0001/0005/0013. Not run: build, tests, `pnpm check`.
Licence evidence is from local package.json / LICENSE files; no web lookups. Not legal advice. Items marked
LEGAL are suggestions for a lawyer or the owner to confirm.

Result: no GPL/LGPL/AGPL, NC/ND, SA, unknown or unregistered licence in anything that ships. The only
copyleft is mediabunny (MPL-2.0), under the ADR-0005 scoped exception. One deliberate release blocker (DEP-14).

## Findings

**F-1 (blocker, known, recorded only). DEP-14 music is placeholder.** Three generated tones (DEP-41..43, status
`proposed`) are bundled in `src/assets/music/` and appear in `dist/assets/` and in the notices file ("Licence:
Placeholder, not for release"). The pack has 3 tracks and RULE-12 needs 8 or more. `pnpm check:release` is designed to
fail on this (placeholders and fewer than 8 tracks). Fix: pick 8 or more CC0 tracks. Each needs a registry row (title,
author, source URL, licence, date checked, saved dedication page, SHA-256), then DEP-14 and the track rows move to
`approved`, and the placeholders are deleted and DEP-41..43 set to `removed`. Avoid CC-BY, SA, NC, ND, Pixabay licence
and account-bound licences (D-010). LEGAL: CC0 does not cover third-party rights the uploader did not hold, so prefer
sources with a verifiable original author, and check composition and performance rights.

**F-2 (info). Copyleft summary.** The only shipped copyleft is mediabunny MPL-2.0 (file-level copyleft; used unmodified,
no `@mediabunny/*`). Build/test-only MPL-2.0 (lightningcss, axe-core), CC-BY-4.0 data and LGPL WebKit are inside ADR-0001
rule 2. `scripts/check-licenses.mjs` encodes these as name-pinned allowlists (`RUNTIME_EXCEPTIONS`,
`BUILD_ONLY_EXCEPTIONS`), so any new MPL/CC-BY package fails the audit. The script also enforces that every direct
dependency is registered and in range, that the prod tree is registered, and that music and looks have rows. Its
`--release` mode is what blocks F-1. No gap found in the script.

**F-3 (low). MPL-2.0 obligations for mediabunny.** The notices file includes the full MPL text and a link to the exact
version's source (`github.com/Vanilagy/mediabunny/tree/v1.65.0`) and says "used unmodified". It does not carry
mediabunny's own copyright line (the notice is the licence text only). MPL 2.0 section 3.2 requires telling recipients
how to get the source for the Executable Form: satisfied by the link. Suggested fix: confirm the bundled worker
chunks keep mediabunny's licence header or comment (the dist scan reads the hidden sourcemaps; hidden maps are kept off
the host via `.assetsignore`). LEGAL: confirm that a link to a third-party repo is an adequate source offer, or mirror
the source tarball in the deploy.

**F-4 (low). Test fixture provenance is undocumented.** Recorded phone clips are mandated by ADR-0016, and the files here
look self-made, but nothing in the repo states who made each file or that it is the owner's own content. Fix: add a short
`tests/fixtures/media/PROVENANCE.md` (tool and command, or "owner recording", with consent for any person visible or
audible) before the repo is made public. The `dmg-*.mp4` and `mp4-*.mp4` files should say they are generated or derived
from own material.

**F-5 (low, docs). Stale registry header.** The status paragraph at the top of `dependencies.md` still says open items
are DEP-12 and DEP-26 (`needs-owner`), but DEP-12 is approved (D-048) and DEP-26 is `removed` (D-047). Fix: edit the
paragraph so it lists only DEP-14 and DEP-41..43. This needs a spec change, so it is not made here.

**F-6 (low). Attribution coverage of the notices page.** `public/third-party-notices.txt` (also in `dist/`) and the in-tool
view (`src/app/notices.gen.ts`, reached from the Music picker and status bar) cover all 10 shipped packages plus
signals-core, the Feather MIT notice, the five OFL texts with copyright lines, mediabunny's MPL text with source link,
and caniuse-lite. Not listed: the owner's looks and tokens (own work, so no obligation). Gap: `gen-notices.mjs` hard-codes
`SOURCE_REPO = github.com/thanh-taro/clip-maker` for own assets (F-020.R3); confirm the repo exists and is public, or
the link is dead. Also, once real CC0 music lands, the notices must list title, author, source and licence per track
(ADR-0001 rule 7). The generator already does this from music.json.

**F-7 (info). Personal-only / needs-owner items.** None in the registry (no row is `personal-only`). DEP-26 is
`removed`, DEP-34 (Chrome) is dev-only and owner-approved. Nothing `personal-only` or unregistered ships.

**F-8 (info). Registry status vs reality.** All 13 prod packages and all direct devDependencies map to approved rows.
DEP-13 `approved` and DEP-12 `approved` are correct. Only DEP-14 and DEP-41..43 are `proposed` (correct while
placeholders ship). The check script's `--strict` mode currently counts these as pending, so `pnpm check:licenses --strict`
is expected to fail until F-1 is resolved, unless the script's pending list excludes them. I did not run it.

**F-9 (info). Package license field.** The project's own package.json says `UNLICENSED`. Decide the outbound licence
(or keep it proprietary) before any public source release. LEGAL if the owner wants to publish source: MPL-2.0 file-level
copyleft does not touch own files when mediabunny is unmodified.
