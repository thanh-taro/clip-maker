42. **F-015.AC14 limit on WebKit:** WebKit partitions storage by top-level site, so the tool embedded in the portal and the tool opened standalone have separate origin-private file systems; each is swept only when the tool next opens in that same context. 44. **Liveness and dead workers.** Silent phases (waiting for the sound, spill replay, writing the index, verify-and-trim decodes) post liveness beats, and in a video export the export-audio worker's beats count too, so hide-and-return does not interrupt a working export.
